
<p>Mini Project 01: Professional Laravel Development Environment Setup</p>

<p>Laravel is a free, open source PGP web framework created in 2011. Its main goal is to make web develop simpler and faster by providing smooth, elegant syntax, and a robust set of built in tools. it follows a MVC or Model View Controller architectural pattern.</p>

<p>CLIENT SERVER TECHNOLOGIES</p>
<p>This program teaches students how modern applications are built, it moves beyond just writing code for a single computer, and teaches students how to make two or more computers communicate over a network to share data and processing power</p>

<p>PURPOSE OF THE PROCJECT</p>
<p>The main purpose and key reason for this project is for students to create a working environment so that they can build a modern, secure, and organized, web application without starting from scratch.</p>

<p>OBJECTIVES</p>
<p>1. Learned how to install and run a laravel application, and its needed components.</p>
<p>2. Learned how to edit a laravel apps main page, and run it via server.</p>
<p>3. Learned the purpose of laravel apps importance for up and coming developers.</p>
